# Monitoring & Observability Platform

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Production-style microservice monitoring and observability platform with Prometheus, Grafana, Alertmanager, and AI-powered incident intelligence.

## Overview

This project demonstrates a production-oriented monitoring and observability platform designed for a distributed microservice application.

The platform focuses on:

- Application and infrastructure monitoring
- Metrics collection and visualization
- Centralized alerting
- Structured application logging
- Automated incident analysis
- AI-assisted root cause analysis
- Alert correlation and anomaly detection
- Incident timeline and report generation
- Failure simulation and recovery workflows

## Technology Stack

- Java 17
- Spring Boot
- PostgreSQL
- Docker
- Docker Compose
- Prometheus
- Grafana
- Alertmanager
- AI / AIOps
